# MyFlix Frontend

Features implemented:
- User authentication (mocked) with login and signup
- Personalized header context "For [Name]"
- Home feed with hero, filter chips, and multiple horizontal carousels
- Search page with instant results
- Details page with Play and My List CTAs
- Watchlist with add/remove and persistence (localStorage)
- Playback modal (mocked video)
- Responsive design using CSS variables and flex/grid

Routes:
- / (Home - protected)
- /search (Search - protected)
- /details/:id (Details - protected)
- /watchlist (Watchlist - protected)
- /login, /signup

To run:
- npm install
- npm start
